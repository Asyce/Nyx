# Achievement page redesign mockup

Standalone interactive mockup for Genshin Impact and Honkai: Star Rail.

Open `achievement-redesign.html` through a local server rooted at the repository so it can read the checked-in achievement catalogs and icons:

```powershell
python -m http.server 5151 --bind 127.0.0.1
```

Then visit:

`http://127.0.0.1:5151/docs/mockups/achievement-redesign-2026-07/achievement-redesign.html`

This mockup intentionally does not touch the production achievement components or shared stylesheet. It is a visual and interaction proposal only.
